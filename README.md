# Simon Says Game 🎮🧠

A fun, interactive, and fully responsive memory-testing game inspired by the classic electronic game "Simon". This project was built to master core algorithmic thinking, state tracking, and user event handling in JavaScript.

## 🚀 Live Demo
👉 **https://github.io**

## ✨ Key Features
- **Dynamic Game Logic:** Automatically generates random color sequences that grow progressively longer as the player wins each round.
- **Score Tracking:** Tracks the player's highest score (High Score) and current level in real-time.
- **Visual Feedback:** Implemented flash animations when a button is selected by the game or pressed by the user, alongside a full-screen flash on game-over.
- **Responsive Layout:** Designed to ensure smooth gameplay on mobile screens, tablets, and laptops.

## 🛠️ Tech Stack Used
- **HTML5:** Structured semantic elements for the game board and display boards.
- **CSS3:** Designed the retro-gaming pad layout with box-shadows, glow transitions, and responsive centering.
- **JavaScript (ES6):** Powering the entire game loop, array comparison algorithms, sound execution, and state manipulation.
